# Potato Disease Dataset Explorer

A beginner-friendly Python command-line project for exploring a small sample dataset of potato leaf disease labels.

## Features

- View the total number of sample records.
- Count records in each disease category.
- Search records by disease name.
- Add a new sample record to the CSV file.

## Technologies

- Python 3
- CSV file handling
- Basic functions, loops, conditionals, and lists

## Project files

- `main.py` — the program.
- `sample_data.csv` — a small example dataset.

## How to run

1. Install Python 3 if it is not already installed.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

   ```bash
   python main.py
   ```

   On some computers, use `python3 main.py`.

5. Choose an option from the menu.

## Dataset note

The CSV file contains illustrative sample labels and filenames. The image files themselves are not included. This project analyzes labels only; it does not inspect leaf images or predict diseases.

## Learning outcomes

This project demonstrates beginner Python programming, reading and writing CSV files, data counting, searching, and building a simple menu-driven application.
